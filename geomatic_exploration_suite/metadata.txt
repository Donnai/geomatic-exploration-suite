about=Combines the supplied radiometric workflow and seismic CDP/SEG-Y tools in one QGIS plugin with a shared dock, menu and user guide. Radiometric tools support input QC, conditioning, U/Th, U/K, K/U and K/Th ratios, threshold review, RRAI-U/HRAI-KU/HRI combination and anomaly extraction. Seismic tools create interval annotation points and convert SEG-Y navigation headers to point/line layers and CSV/ASCII outputs. Requires QGIS Python, NumPy and GDAL. SEG-Y conversion additionally requires segyio in the QGIS Python environment. Outputs require suitable input CRS, units and dataset checks; diagnostic indices are not direct proof of hydrocarbons.
